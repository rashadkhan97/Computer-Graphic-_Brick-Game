# DX Ball Game (Brick Breaker)

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

**DX Ball Game** is a brick-breaker style game developed using **Python** as part of my Computer Graphics course. The game is inspired by the classic DX Ball game, where the player controls a paddle to bounce a ball and break bricks.

---

## 🎮 Features
- Break multiple rows of bricks with a bouncing ball.  
- Control the paddle to prevent the ball from falling.  
- Score points for each brick destroyed.  
- Simple and interactive graphics implemented using Python.
